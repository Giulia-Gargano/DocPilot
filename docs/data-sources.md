# Document sources

This file records the documents selected for the first DocPilot dataset.

## Selection criteria

- Public technical documentation
- Clearly identifiable source and version
- Permission or licence suitable for the intended use
- A small, coherent topic
- No personal, confidential, or company-internal information

## Dataset policy

Raw documents and generated indexes are excluded from Git by default.

Before publishing document content, check its licence and usage terms.
Whenever practical, provide a reproducible ingestion process instead
of redistributing the original documents.
